# 모바일 OTP — TOTP 2단계 인증 (`26-w11-mobile-otp`)

> **한국폴리텍대학 강서캠퍼스 사이버보안과 1학년 「웹콘텐츠 제작」 11주차 과제**  
> 외부 서버 전송 없는 순수 클라이언트 기반 모바일 OTP(TOTP 2단계 인증) 체험 스튜디오 웹앱

---

## 🌟 프로젝트 소개

스마트폰의 Google Authenticator 및 Microsoft Authenticator 앱과 **인터넷 연결 없이도 30초마다 정확히 동일한 6자리 일회용 비밀번호를 생성·동기화하는 모바일 OTP 체험 스튜디오**입니다.

사용자가 '인증을 요구하는 서비스 서버'와 '일회용 번호를 확인·입력하는 스마트폰/인증기'의 동작 메커니즘을 한눈에 직관적으로 비교·실습할 수 있도록 **좌우 2단 분할 다크 보안 대시보드 레이아웃**으로 설계되었습니다.

- **[좌측 패널] 서비스 설정 & QR 등록 (서버 역할)**: 발급자(`Issuer`)와 계정명(`Account`)을 커스텀하고, CSPRNG 20바이트 암호학적 난수로 생성된 공유 비밀 키(Base32) 및 모바일 앱 등록용 `otpauth://` QR 코드를 즉시 발급합니다. 하단에는 Unix Timestamp, 30초 스텝 카운터, 64-bit Big-Endian Hex 바이트 덤프를 실시간으로 투시합니다.
- **[우측 패널] 실시간 OTP & 2단계 인증 검증 (인증기 & 검증 역할)**: 30초 원형 SVG 카운트다운 게이지(잔여 5초 긴급 알림)와 실시간 6자리 OTP 번호를 출력하여 스마트폰 화면과 1초의 오차도 없이 일치하는지 육안으로 대조합니다. 사용자가 입력한 번호를 검증 판정하며 시계 오차(±1 step / 30초) 허용 토글 및 검증 감사 로그를 제공합니다.

## 🧭 나의 AI 기획·구현 과정

### 1. AI 협업 방식: Antigravity IDE Implementation Plan 기반 자기주도 설계
- 복사할 프롬프트 없이 **Antigravity IDE의 `/plan` 명령어를 활용**하여 기획 단계부터 시스템 아키텍처 다이어그램, Web Crypto API 모듈 인터페이스, 좌우 2단 컴포넌트 계층 구조를 체계적으로 수립했습니다.
- 보안 원칙(Math.random 완전 배제, Zero-Transmission, RFC 6238/4648 표준)을 기술 제약 조건으로 사전에 정의하고 단계별 세부 계획을 승인한 후 구현에 착수했습니다.

### 2. 구상한 화면 구조 및 데이터 흐름
- **단일 페이지 반응형 2단 그리드**: 데스크톱에서는 좌우 2단으로 서버와 인증기의 연동 흐름을 직관적으로 보여주고, 모바일 기기에서는 1열 세로 스택으로 자동 최적화되도록 구성했습니다.
- **암호학 연산의 순수 모듈화 (`src/utils/totp.js`)**: UI와 비즈니스 로직을 완벽히 분리하여 모든 TOTP/Base32/카운터 연산을 순수 함수 형태로 작성했습니다.

### 3. 구현 중 마주친 과제와 해결 과정
- **64-bit Big-Endian 카운터 버퍼 변환**: JavaScript의 일반 Number는 비트 연산 시 32-bit 부호 있는 정수로 잘리는 한계가 있었습니다. 이를 해결하기 위해 모던 브라우저 표준인 `DataView.prototype.setBigUint64(0, BigInt(counter), false)`(리틀엔디안이 아닌 빅엔디안 플래그 `false`)를 적용하여 8바이트 바이너리 카운터를 완벽히 구성했습니다.
- **RFC 6238 공식 테스트 벡터를 통한 연산 무결성 보장**: 스마트폰 앱 연동 전, RFC 6238 Appendix B의 공식 SHA-1 테스트 벡터(Secret: `GEZDGNBVGY3TQOJQGEZDGNBVGY3TQOJQ`, T=1일 때 `287082`, T=37037036일 때 `081804` 등)를 검증하는 `runRfc6238SelfTest()` 함수를 작성하여 Node.js 및 브라우저 환경에서 5개 테스트 케이스를 모두 통과(PASS)시켰습니다.
- **30초 주기 타이머의 부드러운 UI 갱신**: 1초 단위 타이머 대신 200ms 단위 타이머를 적용하여 원형 프로그레스 바의 회전과 남은 시간 계산이 끊김 없이 매끄럽게 흐르도록 최적화했습니다.

## 🛡️ TOTP 원리 및 보안 점검 (사이버보안과 체크포인트)

### 1. 비밀 키 생성 시 `Math.random()` 대신 `crypto.getRandomValues()`를 사용해야 하는 이유
- `Math.random()`은 암호학적으로 안전하지 않은 의사난수 생성기(PRNG)입니다. 내부 시드값이나 알고리즘 상태가 알려지면 다음 난수를 수학적으로 예측할 수 있어 공격자가 피해자의 2FA 비밀 키를 무차별 대입하거나 유추할 치명적인 취약점이 발생합니다.
- 반면 `window.crypto.getRandomValues()`는 운영체제의 하드웨어 엔트로피 풀(키보드 타이핑, 마우스 움직임, CPU 인터럽트 등)을 소스로 사용하는 암호학적으로 안전한 의사난수 생성기(CSPRNG)입니다. 20바이트(160-bit)의 강력한 무작위성을 보장하므로 예측이 불가능하여 안전한 2FA 공유 시크릿을 발급할 수 있습니다.

### 2. 브라우저 내장 Web Crypto API (`crypto.subtle`) 로컬 연산의 보안상 이점 (Zero-Transmission)
- 외부 서드파티 라이브러리(npm 패키지)에 의존하거나 서버 API로 비밀 키를 전송하여 HMAC 연산을 수행할 경우, 중간자 공격(MITM)이나 서플라이 체인 공격, 서버 유출 사고 시 사용자의 2단계 인증 정보가 탈취될 위험이 있습니다.
- 본 프로젝트는 브라우저 내장 `window.crypto.subtle` API를 사용해 **모든 연산을 클라이언트 메모리 내에서 100% 처리**합니다.
- **Network 탭 점검 결과**: 브라우저 개발자 도구(`F12`)의 **Network** 탭을 활성화한 상태에서 '새 비밀 키 발급', 'QR 코드 생성', '실시간 OTP 계산', '인증 검증'의 모든 과정을 수행해도 **외부 서버로 단 1바이트의 네트워크 패킷도 전송되지 않는 Zero-Transmission(무전송 원칙)**을 완벽히 입증했습니다.

### 3. 스마트폰 Authenticator 앱과의 실시간 일치 검증 결과
- 생성된 QR 코드를 스마트폰의 **Google Authenticator** 및 **Microsoft Authenticator** 앱으로 카메라 스캔하여 계정을 등록했습니다.
- 스마트폰 화면의 6자리 인증 번호와 웹 대시보드 우측의 실시간 6자리 번호가 30초 카운트다운 타이밍에 맞춰 **1초의 오차도 없이 동일하게 변경**되는 것을 확인했습니다.
- 스마트폰에 표시된 숫자를 [2단계 인증 로그인 시뮬레이터]에 입력하고 검증을 수행했을 때 즉시 **✅ 2단계 인증 통과(Success)** 피드백을 수신했습니다.

## 💡 나만의 차별화 및 확장 기능

1. **원형 SVG 카운트다운 게이지 & 시각적 긴급 경고**:
   - 30초 주기를 원형 게이지로 실시간 시각화하고, 잔여 시간이 10초 이하(주의: 주황색), 5초 이하(긴급: 붉은색 펄스 애니메이션)일 때 시각적으로 경고하여 만료 직전 번호 입력을 방지합니다.
2. **시간 오차 허용 (±1 스텝 / 30초 전후) 시뮬레이션 토글**:
   - 스마트폰과 서버 간의 실제 하드웨어 시계 오차(Clock Drift)나 네트워크 지연에 대비해 이전 스텝(-1)과 다음 스텝(+1)까지 유효한 토큰으로 인정할지 선택하는 토글 스위치를 탑재했습니다. 검증 성공 시 몇 초의 오차로 통과했는지 메타 태그로 안내합니다.
3. **서버 내부 연산 상태 투시 박스 (교육적 시각화)**:
   - 일반 사용자가 이해하기 어려운 TOTP의 수식을 풀어서 Unix Timestamp(ms/s), 30초 카운터 수치 `T = floor(UnixTime / 30)`, 그리고 HMAC-SHA1에 실제 입력되는 8바이트 Hex 바이너리 덤프를 실시간으로 투시합니다.
4. **검증 감사 로그 (Audit History) 타임라인**:
   - 사용자가 시도한 최근 5회의 인증 시도(입력 코드, 성공/실패 여부, 판정 시각, 상세 사유)를 기록하여 모의 침투 및 인증 테스트 과정을 가시적으로 추적할 수 있도록 구현했습니다.
5. **원클릭 빠른 테스트 & 클립보드 복사 UX**:
   - 스마트폰 없이도 PC 브라우저만으로 즉시 검증 테스트를 해볼 수 있는 '현재 OTP 자동 입력' 버튼 및 키/OTP 원클릭 복사 토스트 기능을 제공합니다.
